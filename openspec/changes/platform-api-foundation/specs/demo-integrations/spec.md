## Requirements

### Requirement: Локальные детерминированные моки
Система SHALL предоставлять моки ФНС, БКИ, счёта и АБС без сетевых вызовов.

#### Scenario: Загрузка профиля
- **WHEN** сервис запрашивает данные по ИНН демо-персоны
- **THEN** соответствующий mock возвращает данные из `personas.json` с воспроизводимым результатом.

### Requirement: Ошибка внешнего источника
Моки SHALL поддерживать контролируемый режим недоступности источника.

#### Scenario: Источник недоступен
- **WHEN** mock включён в error mode
- **THEN** сервис не теряет заявку и создаёт результат с `SOURCE_UNAVAILABLE` или маршрутом `UNDERWRITING`.
