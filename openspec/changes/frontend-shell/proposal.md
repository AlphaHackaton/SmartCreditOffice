# Proposal

## Why

В репозитории отсутствует frontend: Dev 3 нужна запускаемая основа для клиентского и банковского контуров. Изменение реализует первый этап плана `docs/ARCHITECTURE.md:621–690`, опираясь на SPEC §2.1 (desktop Web), §4 (сквозной путь), §5 Q55 (два контура в одном интерфейсе) и Q58 (фирменный стиль).

## What Changes

- Создать `frontend/` на React 18, TypeScript strict и Vite; подключить Alfa Core Components, TanStack Query, react-router, ESLint, Vitest и Testing Library.
- Добавить общий desktop layout, навигацию клиентского и банковского контуров, маршруты с честно обозначенными заглушками и страницу неизвестного адреса.
- Подготовить fetch-обёртку `/api/v1`, обработку ошибок и сброс сессии при 401, изолированный кеш запросов и команду генерации типов из OpenAPI.
- Зафиксировать границу интеграции: пока Dev 2 не предоставил `docs/openapi.json`, каркас собирается без выдуманных DTO и без запросов к несуществующим endpoint.
- Добавить проверки, документацию запуска, lock-файл и сведения о зависимостях.

## Capabilities

### New Capabilities

- `workspace-navigation`: единый desktop-интерфейс и адресуемые разделы клиента и банка, включая состояния незавершённой функциональности и неизвестного маршрута.
- `api-communication`: единые правила HTTP-запросов, обработки ответов, ошибок, сессии и интеграции с опубликованным контрактом API.

### Modified Capabilities

Нет: основные спецификации пока отсутствуют.

## Impact

Новые файлы преимущественно в `frontend/`; npm-зависимости, `package-lock.json`, `THIRD_PARTY_NOTICES.md` и инструкция запуска. Backend, API endpoint, схемы DTO и модели БД не меняются. Экспорт OpenAPI остаётся ответственностью Dev 2. Breaking changes отсутствуют.

## Вне скоупа

Реальный вход и RBAC, копирование seed-персон, формы заявок, финансовые расчёты, скоринг, симулятор, подпись, метрики и полноценные бизнес-экраны. Docker/nginx относятся к интеграции с Dev 2. Нет мобильной версии, адаптива, лендинга и внешних интеграций. Это каркас для следующего изменения, а не готовый кредитный сценарий.
