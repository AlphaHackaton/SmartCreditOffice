# Spec Delta

## MODIFIED Requirements

### Requirement: Банковский контур
Bank SHALL получать queue/dossier/scoring-runs/metrics и подтверждать decision/rescore. SHALL показывать факторы, policy, исходные данные и результат в читаемых полях, audit без seed. Метрики SHALL ограничиваться опубликованными счётчиками, sandbox/replay не имитируются.

#### Scenario: Ручное решение
- **WHEN** сотрудник подтверждает решение UNDERWRITING
- **THEN** API получает outcome/comment, досье/очередь/метрики перечитываются

## ADDED Requirements

### Requirement: Продуктовая терминология

Страницы клиента и банка SHALL использовать названия бизнес-действий без упоминаний API, backend, mock, Python, синтетических примеров и внутренних контрактов. Факторы, баллы, правила, аудит и доступные действия SHALL сохраняться. Внешние источники остаются локальными детерминированными моками на синтетических данных.

#### Scenario: Рабочие страницы
- **WHEN** пользователь открывает заявку, досье или метрики
- **THEN** видит условия, объяснения и рабочие действия без технических плашек и JSON
