# Spec Delta

## MODIFIED Requirements

### Requirement: Доступность API и демо-учёток

Интерфейс SHALL предлагать вход только по известным пользователю логину и паролю без каталога учётных записей, опубликованного пароля и кнопок входа за другого пользователя. Роль определяется результатом авторизации. Недоступность сервиса SHALL показывать понятную ошибку без имитации успешного входа. Пароли и токены SHALL не попадать в логи и постоянное хранилище браузера.

#### Scenario: Сервер недоступен
- **WHEN** запрос входа не может связаться с сервисом
- **THEN** форма остаётся доступной, показывает ошибку соединения и не создаёт сессию

#### Scenario: Демо-персоны загружены
- **WHEN** посетитель открывает страницу входа
- **THEN** видит поля логина и пароля без списка пользователей и без запроса каталога персон

#### Scenario: Подтверждение роли
- **WHEN** клиент или сотрудник вводит действующие учётные данные
- **THEN** открывается соответствующий роли кабинет
