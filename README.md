# «Умный кредитный кабинет предпринимателя»

Проект команды в рамках хакатона **«Альфа-Будущее 2026» (Альфа-Банк)**.  
Интеллектуальный кредитный конвейер для малого бизнеса (ИП и ООО) с прозрачным скорингом, интерактивным симулятором контрофферов и бесшовным подписанием в веб-интерфейсе.

## ⏱ 3-минутный экспресс-сценарий проверки для жюри

1. **Мгновенное одобрение и выдача (`p1`):**  
   Войдите под **`p1`** (пароль `demo`) на [https://andbel.ru](https://andbel.ru) → подайте заявку на 2 000 000 ₽ на 24 мес → прозрачный скоринг за 1.5 сек → результат `APPROVED` (100 баллов, грейд A) → нажмите «Подписать» → введите код подтверждения из интерфейса → статус «Кредит выдан».
2. **Интерактивный симулятор встречного предложения (`p2`):**  
   Войдите под **`p2`** → заявка 2.5 млн ₽ на 12 мес → вердикт `COUNTER_OFFER` из-за порога DSCR → откроется интерактивный симулятор срока и суммы: подвигайте слайдеры, график платежей и параметры пересчитываются мгновенно.
3. **Заботливый отказ и Explainability (`p4`, `p5`):**  
   Войдите под **`p4`** (текущая просрочка в БКИ) или **`p5`** (молодой бизнес) → результат `REJECTED` с детальным разбором причин, а для `p5` — точная календарная дата, когда бизнес преодолеет 6-месячный порог и сможет взять кредит.
4. **Контур сотрудника банка (`underwriter`):**  
   Войдите под **`underwriter`** → откройте очередь ручной проверки → заявка клиента **`p6`** с риском `FNS_MISMATCH` → изучите скоринговую трассу, сверку выписок с налоговой декларацией → утвердите заявку с комментарием.

## 🚀 Быстрый локальный запуск

### Запуск всего приложения в Docker Compose (CPU-only)
Оптимизирован для ПК жюри (требует 8–12 ГБ RAM, видеокарта не нужна):
```bash
git clone https://github.com/AlphaHackaton/SmartCreditOffice.git
cd SmartCreditOffice

docker compose up --build
```
- **Клиентский и банковский веб-кабинет:** [http://localhost:8080](http://localhost:8080)
- **Backend API & Swagger:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **Health check:** `curl http://localhost:8000/api/v1/health`

### Запуск автоматизированной проверки качества (Харнесс)
```bash
bash scripts/check.sh
```
Скрипт проверяет:
- Backend: линтинг и форматирование (`ruff`), строгая типизация (`mypy`), 807 unit/integration тестов (`pytest`).
- Frontend: проверка типов (`tsc`), линтинг (`eslint`), 332 компонентных и интеграционных теста (`vitest`).
- Контракты: синхронизация и валидация OpenAPI схемы (`docs/openapi.json`).
- Запреты регламента: отсутствие вызовов платных/закрытых внешних API.

## 🛠 Технологический стек

- **Backend:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2, PostgreSQL 16, uv.
- **Frontend:** React 18, TypeScript (strict), Vite, `@alfalab/core-components` (дизайн-система Альфа-Банка), TanStack Query.
- **Инфраструктура:** Docker Compose (db + backend + frontend с nginx-проксированием `/api/`). Полная автономность без внешних рантайм-зависимостей.

## 👥 Распределение ролей в команде

- **Dev 1 (Domain / Risk Core):** Скоринговый движок, FSM статусов заявки, формулы DSCR и аннуитета, Explainability, unit-тесты (TDD).
- **Dev 2 (Platform / API / DB):** FastAPI роутеры, SQLAlchemy/Alembic, моки внешних систем (ФНС, БКИ, банк), сервис авторизации, Docker Compose.
- **Dev 3 (Frontend / UX):** Клиентский путь (витрина, лоадер скоринга, интерактивный симулятор контроффера, подписание), компактный контур андеррайтера (Банк).
