# «Умный кредитный кабинет предпринимателя»

Проект команды в рамках хакатона **«Альфа-Будущее 2026» (Альфа-Банк)**.  
Интеллектуальный кредитный конвейер для малого бизнеса (ИП и ООО) с прозрачным скорингом, интерактивным симулятором контрофферов и бесшовным подписанием в веб-интерфейсе.

---

- **[Мастер-архитектура и планы разработки (ARCHITECTURE.md)](docs/ARCHITECTURE.md)** — подробная финтех-архитектура, FSM, 6 seed-персон, DTO и персональные планы участников команды.

## 🛠 Технологический стек

- **Backend:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2, PostgreSQL 16, uv.
- **Frontend:** React 18, TypeScript (strict), Vite, `@alfalab/core-components` (дизайн-система Альфа-Банка), TanStack Query.
- **Инфраструктура:** Docker Compose (CPU-only, оптимизирован под 8–12 ГБ RAM для проверки жюри).

---

## 👥 Распределение ролей в команде (Схема по слоям)

- **Dev 1 (Domain / Risk Core):** Скоринговый движок, FSM статусов заявки, формулы DSCR и аннуитета, Explainability, unit-тесты (TDD).
- **Dev 2 (Platform / API / DB):** FastAPI роутеры, SQLAlchemy/Alembic, моки внешних систем (ФНС, БКИ, банк), сервис авторизации, Docker Compose.
- **Dev 3 (Frontend / UX):** Клиентский путь (витрина, лоадер скоринга, интерактивный симулятор контроффера, подписание), компактный контур андеррайтера (Банк).

## Текущее состояние frontend

Реализован desktop-кабинет в явном mock-режиме: демо-вход и роли, профиль/продукты/заявки, форма с черновиками и согласиями, подача, статусы, история и опрос проверки. Демо-данные и последовательности генерируются из backend seed/политики/FSM; финансовых расчётов в JS нет. Служебные бизнес-экраны и подробные офферы/подписание — следующие этапы. HTTP API-сервер и Compose пока отсутствуют, API-режим не подменяется моками. Запуск и сценарии проверки: [frontend/README.md](frontend/README.md).

## 🚀 Быстрый запуск

### 1. Разработка frontend сейчас

Среда Dev 3: [DEV_CODEX.md](DEV_CODEX.md). Рабочая ветка — `codex/frontend-development`: frontend объединён с доменным backend из `origin/main`.

Из корня репозитория:

```bash
npm ci --prefix frontend
npm run dev --prefix frontend
```

Веб-интерфейс: `http://localhost:5173`. Для текущего каркаса API, БД, Docker и LLM не нужны. Тесты/сборка: `npm test --prefix frontend -- --run`, `npm run build --prefix frontend`.

### 2. Запуск локальной проверки харнесса
```bash
UV_CACHE_DIR="$PWD/tmp/uv-cache" uv sync --project backend --locked
bash scripts/check.sh
```

### 3. Полный запуск после подключения платформы Dev 2

`backend/app/main.py`, `docs/openapi.json` и Compose пока отсутствуют. Команды `uv run uvicorn app.main:app --reload` и `docker compose up --build` станут доступны после появления соответствующих файлов. Скоринговое ядро работает и тестируется отдельно; оно не является HTTP API.
