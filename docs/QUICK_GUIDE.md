## 3. Суть продукта (что мы строим)

**Веб-сервис кредитного конвейера для малого бизнеса (ИП и ООО).**  
Связывает в едином интерфейсе путь предпринимателя и внутреннюю обработку банком:
1. **Потребность:** клиент выбирает задачу (оборотный кредит, овердрафт, покупка оборудования).
2. **Заявка:** ввод суммы и срока. Реквизиты компании уже предзаполнены.
3. **Скоринг банка:** расчет риска и платежеспособности через моки (БКИ, ФНС, выручка).
4. **Решение банка:** 3 обязательных исхода — *Одобрение*, *Встречное предложение* (меньшая сумма / другая ставка) или *Отказ*.
5. **Выдача:** условное подписание договора внутри ЛК (код/кнопка) и смена статуса на «Кредит выдан».

## 4. Жесткие ограничения (ГДЕ МОЖНО СРЕЗАТЬСЯ)

* 🚫 **Только десктопный Web:** Мобильные приложения строго запрещены регламентом.
* 🚫 **Никаких платных API в рантайме:** Запрещены вызовы GPT-4, Claude, Яндекс OCR и закрытых сервисов. Разрешены только **Open Weights** модели (Qwen, Llama, Mistral) через OpenAI-совместимый интерфейс.
* 🚫 **Никаких SMS, звонков и Email в сценарии:** Весь процесс (включая авторизацию и подписание) должен происходить **строго внутри веб-интерфейса**.
* 🚫 **Железо экспертов (CPU-only):** Проверка будет на обычном ПК без видеокарты (**8–12 ГБ RAM**). Тяжелые модели в Docker приведут к зависанию и незачету.
* 🚫 **Никаких реальных банковских интеграций:** Все внешние базы (ФНС, БКИ, CRM) должны быть локальными моками.

## 5. Что можно НЕ ДЕЛАТЬ (легальная экономия времени)

1. ⚡ **«Новостную ленту» из ТЗ делать НЕ НАДО:** Это опечатка организаторов, пункт попал из соседнего трека.
2. ⚡ **Сбор документов и регистрацию юрлица делать НЕ НАДО:** Пользователь уже действующий клиент, данные компании предзаполнены.
3. ⚡ **Отдельный интерфейс для сотрудника банка НЕ НАДО:** Достаточно одного интерфейса с переключением ролей («Клиент» / «Банк») или наглядным отображением этапов.
4. ⚡ **Обучать реальную ML-модель НЕ НАДО:** Официально разрешены детерминированный скоринг (по правилам/баллам) или заглушка-мок (stub) вместо модели.
5. ⚡ **Автоматический OCR-парсинг выписок НЕ НАДО:** Это опциональная фича, не входящая в базу MVP.
6. ⚡ **Адаптивную верстку и лендинг делать НЕ НАДО:** Достаточно качественного десктопного веб-экрана.
7. ⚡ **Вайбкодинг разрешен:** Разрабатывать проект с помощью Cursor, Claude или Copilot разрешено на 100%.
